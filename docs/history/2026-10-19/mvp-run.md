- Не более двух исполнителей одновременно; ревью запускается координатором после освобождения двух слотов.
- Worktree созданы обычным `git worktree add` внутри игнорируемой `.worktrees/`, не управляемым инструментом приложения. Очистка после подтверждения сохранности результатов.
- Для Node.js используется runtime `C:/Users/User/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin`; системный nvm shim не настроен. Bun 1.4.2 доступен.
- Docker daemon не запущен. Работающий локальный PostgreSQL 18 используется через отдельную роль и отдельные базы с суффиксом `_test`. Development/production данные не мигрируются.
- Локальные параметры тестовых баз и служебные скрипты находятся в игнорируемой `.mvp-local/`; credentials не добавляются в Git. Базы issue2/issue3/integration изолированы; порты #2: 55520/55521, #3: 55530/55531.
- Снимки GitHub issues доступны исполнителям вне репозитория: `C:/Users/User/.codex/visualizations/2026/10/19/01a154f2-c730-7683-8b89-d9041a09ea37/issues/`.
- GitHub connector читает issues, но создание PR вернуло 403. Для операций трекера используется portable gh из `%TEMP%/govolley-mvp-tools/bin` через `.mvp-local/gh.ps1` и существующий Git credential без вывода токена.
