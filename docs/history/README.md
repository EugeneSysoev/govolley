## Как читать историю

Перед изменениями сверяйте исторический результат с текущим кодом и открытыми замечаниями. Исправления 2026-10-18 и дополнительные находки 2026-10-19 имеют разный охват: сохранённый статус F1–F14 не закрывает автоматически новые SPEC-xxx и STD-xxx.

Исторические отчёты сохраняйте как снимки результата на указанную дату. Актуальные статусы новых замечаний ведите в файле ревью и согласованном трекере; при последующих исправлениях добавляйте отдельную запись с результатами проверок.
