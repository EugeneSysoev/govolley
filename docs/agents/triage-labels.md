# Triage Labels

Пять канонических ролей triage соответствуют следующим меткам в GitHub Issues проекта.

| Роль навыка | Метка в трекере | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Задача ожидает оценки сопровождающим проекта. |
| `needs-info` | `needs-info` | Для продолжения нужна информация от автора задачи. |
| `ready-for-agent` | `ready-for-agent` | Требования определены, задача готова к самостоятельной реализации агентом. |
| `ready-for-human` | `ready-for-human` | Задача требует реализации человеком. |
| `wontfix` | `wontfix` | Задачу решено не выполнять. |

Когда навык указывает роль triage, используйте соответствующую метку из таблицы. Если названия меток в проекте изменятся, обновите столбец «Метка в трекере» здесь.
