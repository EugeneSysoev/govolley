# Domain Docs

## Схема: single-context

GoVolley использует один общий доменный контекст для backend, frontend и shared-types. Глоссарий и описание модели располагаются в корневом `CONTEXT.md`, архитектурные решения — в `docs/adr/`.

## Что читать перед изучением кода

1. Прочитайте корневой `CONTEXT.md`.
2. Прочитайте ADR из `docs/adr/`, затрагивающие область задачи.
3. Если впоследствии появится корневой `CONTEXT-MAP.md`, используйте его указатели на контексты, относящиеся к задаче.

Если этих файлов пока нет, продолжайте работу без замечаний об их отсутствии. Навык `domain-modeling` создаёт их по мере согласования терминов и решений; при начальной настройке достаточно этой конфигурации.

## Терминология

Используйте термины, определённые в `CONTEXT.md`, в описаниях задач, гипотезах, тестах и предложениях по рефакторингу. Если нужного понятия нет в глоссарии, сначала проверьте существующую терминологию кода; реальный пробел отмечайте для `domain-modeling`.

## Архитектурные решения

Если предложение противоречит существующему ADR, явно укажите решение, причину противоречия и основание для его пересмотра. Изменение решения фиксируйте новым ADR или по принятому в существующих ADR порядку.
